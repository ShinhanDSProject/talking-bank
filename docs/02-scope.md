# 02. 범위

> 범위를 바꿀 때는 이 문서를 먼저 고친다. 각 Phase의 화면·정책·요구사항은 [`requirements/`](requirements/), 기능 명세·모델·진행 순서는 [`domains/`](domains/) 아래 문서에 있다.

## 원칙

- **AI는 돈을 움직이지 않는다.** 읽기와 초안뿐이다. 실행은 사람의 확인과 이체 비밀번호로만.
- **한 번에 한 Phase.** Phase 1이 배포 주소에서 돌기 전에 Phase 2 코드를 쓰지 않는다.
- **핵심 흐름 하나만.** 비서는 "말 → 초안 → 확인 → 실행" 한 줄이지, 금융 상담 봇이 아니다.
- **어느 Phase에서 멈춰도 동작하는 결과물이 남는다.**

## Phase 개요

| Phase | 도메인          | 코어와의 연결점                                                        | 핵심 흐름                                                                                     | 배치 | 문서                                                                                                              |
| ----- | --------------- | ---------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- | ---- | ----------------------------------------------------------------------------------------------------------------- |
| **1** | **은행 코어**   | —                                                                      | 가입 → 로그인 → 계좌 → 이체 → 거래내역                                                        | 없음 | [requirements/01-core.md](requirements/01-core.md) · [domains/01-core.md](domains/01-core.md)                     |
| **2** | **대화형 뱅킹** | 조회 API를 읽고 `Transfer.DRAFT`를 만든다. 출금 평가 훅에 FDS 규칙 2개 | 말 → 의도 → 도구 호출 → 되읽기 → 초안 → 확인 화면 → 이체 비밀번호 → 실행 / 보류 → 설명 → 인증 | 없음 | [requirements/02-assistant.md](requirements/02-assistant.md) · [domains/02-assistant.md](domains/02-assistant.md) |

**프로젝트는 Phase 2에서 끝난다.** Phase 2의 필수 요구사항이 전부 끝나고 시연 장면이 완주되면 완료다.

## 향후 확장 후보

이번 프로젝트 범위에 없다. 코어가 열어둔 자리([04-domain.md](04-domain.md#이후-phase를-위해-코어가-열어둘-자리))와 연결점만 문서로 남긴다. 착수한다면 아래 순서가 의존성에 맞다.

| 후보           | 코어와의 연결점                      | 핵심 흐름                                                        | 필요한 인프라                | 문서                                                   |

| 리스크 전체    | 출금 평가 훅                         | 차단(`BLOCKED`) · 1일 누적 한도 · 관리자 이상거래 화면 · ML 점수 | 없음                         | [domains/02-risk.md](domains/02-risk.md)               |

| 증권           | 증권 계좌 입금이 은행 계좌에서 출금  | 예수금 입금 → 가상 매수/매도 → T+2 결제                          | 상품의 배치 인프라           | [domains/06-securities.md](domains/06-securities.md)   |
