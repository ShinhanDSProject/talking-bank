# 02. 범위

> 범위를 바꿀 때는 이 문서를 먼저 고친다. 각 Phase의 기능 명세·모델·진행 순서는 [`domains/`](domains/) 아래 도메인 문서에 있다.

## Phase 개요

| Phase | 도메인         | 코어와의 연결점                      | 핵심 흐름                                                           | 배치                       | 문서                                                   |
| ----- | -------------- | ------------------------------------ | ------------------------------------------------------------------- | -------------------------- | ------------------------------------------------------ |
| **1** | **은행 코어**  | —                                    | 가입 → 로그인 → 계좌 → 송금 → 거래내역                              | 없음                       | [domains/01-core.md](domains/01-core.md)               |
| 2     | 리스크 (FDS)   | 이체의 출금 평가 훅에 규칙을 꽂는다  | 송금 요청 → 규칙 평가 → 정상 / 보류(추가 인증) / 차단 → 관리자 확인 | 없음                       | [domains/02-risk.md](domains/02-risk.md)               |
| 3     | 여신/수신 상품 | 예금·대출 계좌가 입출금 계좌에 연결  | 적금 가입 → 자동이체 납입 → 만기 해지 / 대출 실행 → 원리금 상환     | 자동이체, 이자 계산, 연체  | [domains/03-product.md](domains/03-product.md)         |
| 4     | 오픈뱅킹       | 우리 계좌를 외부 앱에 노출           | 외부 앱 등록 → OAuth 동의 → 계좌 조회·이체 API 호출                 | 동의 만료 관리             | [domains/04-openbanking.md](domains/04-openbanking.md) |
| 5     | 카드           | 체크카드가 입출금 계좌에서 즉시 출금 | 결제 승인 → 계좌 출금 → 매입 → 가맹점 정산                          | 일마감 매입, 정산 지급     | [domains/05-card.md](domains/05-card.md)               |
| 6     | 증권           | 증권 계좌 입금이 은행 계좌에서 출금  | 예수금 입금 → 가상 매수/매도 → 체결 → T+2 결제                      | T+2 결제, 일일 평가        | [domains/06-securities.md](domains/06-securities.md)   |
| 7     | 보험           | 보험료가 은행 계좌에서 자동이체      | 청약 → 승인 → 보험료 납입 → 만기 환급 / 실효                        | 보험료 자동이체, 만기 도래 | [domains/07-insurance.md](domains/07-insurance.md)     |

순서의 근거는 의존성이다.

- **Phase 2(리스크)** 는 코어 바로 다음이다. 규칙 3~4개라 작고 배치가 필요 없다.
- **Phase 3(여신/수신 상품)** 이 Spring Batch·자동이체·영업일 캘린더를 처음 도입한다. 카드·증권·보험은 전부 이 인프라를 쓰므로 Phase 3 뒤에 온다.
- **Phase 4(오픈뱅킹)** 는 배치 의존이 없어 Phase 1 완료 후 어디에 두어도 된다.
- **Phase 5~7(카드·증권·보험)** 은 서로 독립이라 순서를 바꿔도 된다.

한 번에 한 Phase만 진행한다.
