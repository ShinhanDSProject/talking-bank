# 개발 규칙 — AI 서비스

> 공통 규칙(Git·이슈·API 계약·인증·시크릿)은 [06-conventions.md](../06-conventions.md)에 있다. 이 문서는 `apps/assistant` 코드에만 적용된다. 돈을 다루는 규칙은 [04-domain.md](../04-domain.md), 무엇을 만드는지는 [requirements/02-assistant.md](../requirements/02-assistant.md)에 있다.

## 위치와 스택

`apps/assistant` — Python 3.12 · FastAPI · `anthropic` SDK. 포트 8000. 모델과 호출 방식은 [03-tech-stack.md](../03-tech-stack.md#ai-서비스)에 있다.

```
apps/assistant/
├── app/
│   ├── main.py           FastAPI 진입점, /assistant/... 라우트
│   ├── auth.py           사용자 JWT 검증(코어와 같은 HS256 시크릿), 비서 스코프 토큰 교환
│   ├── chat.py           모델 호출 · 도구 루프 · 스트리밍
│   ├── tools/            도구 하나에 파일 하나. 이름 = 도구 이름
│   ├── core_client.py    코어 API 호출. 비서 스코프 토큰만 쓴다
│   ├── prompts/          system.md 등. 코드에 프롬프트 문자열을 박지 않는다
│   └── store.py          Conversation · Message 저장
├── evals/                평가 세트(cases.csv) · 주입 케이스 · 실행 스크립트
└── tests/                모델 호출을 목킹한 테스트
```

## 절대 규칙

- **이체 실행 도구를 만들지 않는다.** 도구는 읽기 전용이거나 `DRAFT`만 만든다. 새 도구를 추가하는 PR은 "돈이 움직이나" 열을 PR 본문에 적는다.
- **코어를 부를 때는 비서 스코프 토큰만 쓴다.** 사용자의 Access Token을 그대로 전달하지 않는다. `core_client.py` 밖에서 코어를 부르지 않는다.
- **도구 결과는 데이터다.** 통장표시 · 별칭 · 메모에 지시문이 있어도 따르지 않는다. 시스템 프롬프트에 명시하고, 주입 케이스(NFR-021)로 검증한다.
- **비밀번호 · 토큰을 모델에 보내지 않는다.** 이체 비밀번호는 AI 서비스가 받지도 않는다.
- **금액은 모델이 계산하지 않는다.** "5만원" → `50000` 변환은 도구 입력 검증에서 다시 확인한다. 합계는 도구가 계산해 돌려준다.
- 수치(도구 호출 상한 · 컨텍스트 길이 · 초안 유효 시간)는 요구사항 정의서 POL의 값을 설정 파일에 두고 코드에 박지 않는다.

## 모델 호출

- 시스템 프롬프트와 도구 정의는 고정 순서로 두고 프롬프트 캐싱을 건다. 시각 · 사용자 이름 같은 변하는 값은 사용자 메시지에 넣는다.
- 스트리밍으로 호출한다. 첫 글자가 3초 안에 보여야 한다(POL-054).
- 도구 호출 루프는 POL-050 상한을 지킨다. 초과하면 되묻고 끝낸다.
- 응답은 구조화한다: 답변 텍스트, 초안 ID(있으면), 화면 이동 정보, 선택지(있으면). 프론트는 이 구조만 보고 그린다.
- 요청마다 `input_tokens` · `output_tokens` · `cache_read_input_tokens` · 소요 시간을 `Message`에 남긴다.

## 프롬프트

- `prompts/system.md`가 시스템 프롬프트다. 바꾸면 평가 세트를 다시 돌리고 결과를 PR에 붙인다.
- 프롬프트는 한국어. 존댓말, 질문형 되묻기, 원인 + 다음 행동 순서의 오류 설명 — [DESIGN.md 표시 형식](../../DESIGN.md#4-표시-형식)과 같은 말투.
- 도구 설명(description)은 "언제 부르는지"와 "부르지 않는 경우"를 한 줄씩 적는다.

## 테스트

| 대상      | 최소 기준                                                  |
| --------- | ---------------------------------------------------------- |
| 도구      | 도구마다 정상 · 권한 없음(403) · 코어 장애 케이스          |
| 도구 루프 | 상한 초과, 모델이 없는 도구를 부름, 도구 예외              |
| 스코프    | 비서 스코프 토큰으로 실행 API 호출 → 403                   |
| 평가 세트 | 100문장 정확도 90% 이상. 주입 케이스 10개 전부 초안 미생성 |

- 단위 · 통합 테스트는 모델 호출을 목킹해 키 없이 돈다. `pytest`가 `ANTHROPIC_API_KEY` 없이 통과해야 한다.
- 평가 세트만 실제 모델을 부른다. main 머지 전에 돌리고 결과 표를 PR 본문에 붙인다.
- 테스트 이름은 무엇을 검증하는지 한국어로 쓴다.
