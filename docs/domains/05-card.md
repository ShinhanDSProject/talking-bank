# Phase 5 — 카드

체크카드 결제가 입출금 계좌에서 즉시 출금되고, 매입을 거쳐 가맹점에 정산된다.

- 진입 조건: [Phase 3](03-product.md) 완료 (배치 인프라).
- 코어와의 연결점: 결제 승인 시 [송금 규칙](../04-domain.md#송금-규칙)의 이체 로직을 호출해 계좌에서 출금한다. [출금 평가 훅](02-risk.md)을 통과한다. `Transaction.sourceType`에 `CARD`가 추가된다.
- 배치: 일마감 매입, 가맹점 정산 지급.

## 핵심 흐름

결제 승인 요청 → 은행 계좌 잔액 확인 → 즉시 출금 → 승인 응답. 이후 매입 → 가맹점별 정산 배치.

- 체크카드부터 시작한다. 신용카드(청구 사이클)는 Phase 5 완료 후 향후 후보.
- "승인"과 "매입"이 나뉜다. 승인은 실시간, 매입·정산은 배치.

## 새 모델 후보

`Card`, `Merchant`, `CardApproval`, `Settlement`.

## 완료 조건

결제 승인이 계좌 잔액을 줄이고, 일마감 배치가 가맹점별 정산액을 만든다.
