# 도메인 spec

도메인 하나가 무엇을 책임지고, 어디까지 하고, 어떤 규칙으로 도는지를 한 파일에 적는다.
구현을 보고 쓴 것이 아니라 **구현이 따라야 할 기준**이다. 코드와 어긋나면 둘 중 하나가 틀린 것이니
먼저 어느 쪽이 맞는지 정하고 고친다.

## 목록

| 도메인   | spec                     | 상태            | 책임                                          |
| -------- | ------------------------ | --------------- | --------------------------------------------- |
| 인증     | [auth.md](auth.md)       | 구현됨 (PR #54) | 가입 · 로그인 · 토큰 발급과 재발급 · 로그아웃 |
| 회원     | [user.md](user.md)       | 구현됨 (PR #54) | 회원 정보 조회와 상태                         |
| 계좌     | [account.md](account.md) | 일부 구현       | 계좌 조회                                     |
| 이체     | —                        | 미작성          | 돈을 옮긴다. 착수 전에 spec부터 쓴다          |
| 거래내역 | —                        | 미작성          | 계좌별 입출금 기록                            |

미작성 도메인은 착수하는 사람이 [\_template.md](_template.md)를 복사해 먼저 채운다.
비어 있는 절은 "정하지 않았다"라고 적고 넘어간다. 빈칸으로 두지 않는다.

## 쓰는 법

- **규칙에는 ID를 붙인다.** `AUTH-R03` 처럼. 테스트 이름과 PR 본문에서 이 ID로 가리킨다.
- **수치는 표 하나에만 둔다.** 다른 절과 코드는 설정 키로 가리킨다. 값을 바꿀 때 한 곳만 고친다.
- **이유는 적지 않는다.** 결정만 적는다. 배경이 필요하면 이슈나 PR 링크를 단다.
- **코드 위치를 링크한다.** 읽는 사람이 바로 확인할 수 있어야 한다.
- 표 스키마는 [erd.md](../erd.md)에 있다. 여기서 컬럼을 다시 정의하지 않는다.

## 모든 도메인이 공유하는 것

| 항목             | 내용                                                                                                                                                               |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 오류 응답        | `{ errorCode, message, timestamp, path, fieldErrors? }` — [ErrorResponse](../../apps/api/src/main/java/com/example/talkingbank/common/response/ErrorResponse.java) |
| 오류 코드        | `<도메인>_<번호>` — [ErrorCode](../../apps/api/src/main/java/com/example/talkingbank/common/exception/ErrorCode.java)                                              |
| 입력 검증 실패   | `COMMON_001` + `fieldErrors[]`에 필드별 사유                                                                                                                       |
| 타임존           | `Asia/Seoul`. 응답 시각은 오프셋 포함                                                                                                                              |
| 금액             | `BigDecimal`. `double` · `float` 금지                                                                                                                              |
| 생성 · 수정 시각 | `BaseTimeEntity` (JPA Auditing)                                                                                                                                    |
