# 회원

회원의 정보와 상태를 갖는다. **가입 · 로그인은 [인증](auth.md)이 한다.**

- 상태: 구현됨 (PR #54)
- 코드: [`user/`](../../apps/api/src/main/java/com/example/talkingbank/user)

## 경계

| 한다                                              | 하지 않는다                            |
| ------------------------------------------------- | -------------------------------------- |
| 본인 정보 조회                                    | 가입 · 로그인 · 토큰 → [인증](auth.md) |
| 회원 상태(`ACTIVE` · `LOCKED` · `WITHDRAWN`) 보관 | 회원 정보 수정 (미정)                  |
| 로그인 실패 횟수 · 잠금 시각 보관                 | 회원 탈퇴 (미정)                       |

## API

`/api/users`

| 메서드 | 경로  | 인증         | 요청 | 응답                                                                                                | 오류                    |
| ------ | ----- | ------------ | ---- | --------------------------------------------------------------------------------------------------- | ----------------------- |
| GET    | `/me` | Access Token | —    | 200 [UserResponse](../../apps/api/src/main/java/com/example/talkingbank/user/dto/UserResponse.java) | `AUTH_004` · `AUTH_005` |

## 규칙

| ID         | 규칙                                                                                                    |
| ---------- | ------------------------------------------------------------------------------------------------------- |
| `USER-R01` | 응답에 비밀번호를 **절대** 넣지 않는다                                                                  |
| `USER-R02` | 인증된 요청의 주체는 `userId`다. 필터가 principal에 넣고 컨트롤러가 `@AuthenticationPrincipal`로 받는다 |
| `USER-R03` | 남의 정보를 조회할 수 있는 경로를 만들지 않는다. `/me`만 둔다                                           |
| `USER-R04` | 회원을 가리키는 이름은 `user`로 통일한다 (`User` · `users` · `/api/users`). `member`를 쓰지 않는다      |
| `USER-R05` | 탈퇴 회원은 로그인도 재발급도 되지 않는다                                                               |

## 데이터

- 표: [erd.md](../erd.md)의 `users`
- 상태 전이: `ACTIVE` → `LOCKED`(실패 한도) → `ACTIVE`(잠금 시간 경과) · `ACTIVE` → `WITHDRAWN`

- [ ] 탈퇴를 어떻게 처리하는가 — 상태만 바꾸는가, 개인정보를 지우는가
