# 향후 확장 — 여신/수신 상품

> **이번 프로젝트 범위에 없다.** 프로젝트는 [Phase 2 대화형 뱅킹](02-assistant.md)에서 끝난다. 이 문서는 확장 후보의 연결점 · 모델 후보 · 완료 조건만 남긴 스텁이다.

예금과 대출이 입출금 계좌에 붙는다. 이 Phase에서 **Spring Batch, 자동이체, 영업일/공휴일 캘린더**를 도입하고, 뒤의 Phase가 전부 재사용한다.

- 진입 조건: [Phase 2](02-assistant.md) 완료.
- 코어와의 연결점: 예금·대출 계좌가 입출금 계좌(`Account`)에 연결된다. 납입·상환·지급은 전부 [송금 규칙](../04-domain.md#송금-규칙)을 따르는 이체다. `Account.accountType`에 `DEPOSIT`, `LOAN`이 추가된다.
- 배치: 자동이체 실행, 이자 계산, 연체 관리.

## 핵심 흐름

- **수신(예금)**: 적금 상품 가입 → 매월 은행 계좌에서 자동이체로 납입 → 만기 시 원금 + 이자를 은행 계좌로 지급.
- **여신(대출)**: 대출 신청 → 승인 → 대출금을 은행 계좌로 입금 → 원리금 상환 스케줄 생성 → 매월 자동이체로 상환. 연체 시 등급 변경.
- 이자 계산은 단리/복리 공식을 `BigDecimal`로.

## 새 모델 후보

`Product`(상품 마스터), `DepositAccount`, `LoanAccount`, `RepaymentSchedule`, `AutoTransfer`, `BusinessDay`.

## 완료 조건

적금 자동 납입 배치가 돌고, 만기 시 이자 포함 지급이 거래내역에 남는다.
