# 계좌

돈이 들어 있는 단위. 지금은 **조회만** 한다.

- 상태: 일부 구현 — 목록 조회만 있다
- 코드: [`account/`](../../apps/api/src/main/java/com/example/talkingbank/account)

## 경계

| 한다                                            | 하지 않는다                        |
| ----------------------------------------------- | ---------------------------------- |
| 계좌 목록 조회                                  | 계좌 개설 · 해지                   |
| 잔액 보관                                       | 잔액 변경 → 이체가 맡는다 (미작성) |
| 계좌 상태(`ACTIVE` · `DORMANT` · `CLOSED`) 보관 | 거래내역 → 미작성                  |

## API

`/api/accounts`

| 메서드 | 경로 | 인증                              | 요청 | 응답                                                                                                             | 오류 |
| ------ | ---- | --------------------------------- | ---- | ---------------------------------------------------------------------------------------------------------------- | ---- |
| GET    | ``   | **지금은 불필요** (`ACCOUNT-R01`) | —    | 200 [AccountResponse](../../apps/api/src/main/java/com/example/talkingbank/account/dto/AccountResponse.java)`[]` | —    |

## 규칙

| ID            | 규칙                                                                                                               |
| ------------- | ------------------------------------------------------------------------------------------------------------------ |
| `ACCOUNT-R01` | `GET /api/accounts`는 지금 인증 없이 열려 있다. **회원-계좌 연결이 붙으면 인증을 걸고 본인 계좌만 돌려준다**       |
| `ACCOUNT-R02` | 계좌는 아직 회원과 연결돼 있지 않다. 예금주는 `owner_name` 문자열이다                                              |
| `ACCOUNT-R03` | 잔액은 `BigDecimal`이고 음수가 될 수 없다                                                                          |
| `ACCOUNT-R04` | 응답 DTO의 필드 이름은 웹의 `Account` 타입과 같게 유지한다 ([api.ts](../../apps/web/src/features/accounts/api.ts)) |
| `ACCOUNT-R05` | 잔액을 바꾸는 코드는 이 도메인에 두지 않는다. 돈이 움직이는 길은 이체 하나뿐이다                                   |

`ACCOUNT-R01` · `ACCOUNT-R03` · `ACCOUNT-R05`는 아직 코드로 강제되지 않는다. 잔액을 바꾸는 코드가
없어서다. 이체를 만들 때 함께 넣는다.

## 정책 수치

| 항목        | 값              | 설정 키                 |
| ----------- | --------------- | ----------------------- |
| 통화        | `KRW` · `USD`   | — (`currency` 컬럼)     |
| 잔액 정밀도 | `DECIMAL(19,2)` | — ([erd.md](../erd.md)) |

## 열린 질문

- [ ] 회원과 언제 연결하는가. 연결 전까지 `ACCOUNT-R01`이 구멍으로 남는다
- [ ] 가입 시 계좌를 자동 개설하는가, 별도 개설 화면을 두는가
- [ ] 외화 계좌를 계속 둘 것인가 (지금 시드에 `USD` 계좌가 있다)
