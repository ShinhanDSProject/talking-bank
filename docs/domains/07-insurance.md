# Phase 7 — 보험

보험료가 은행 계좌에서 자동이체되고, 만기·실효·부활이 배치로 처리된다.

- 진입 조건: [Phase 3](03-product.md) 완료 (자동이체 배치).
- 코어와의 연결점: 보험료 납입은 Phase 3의 자동이체로 — [송금 규칙](../04-domain.md#송금-규칙)을 따른다. `Transaction.sourceType`에 `INSURANCE`가 추가된다. 청약 심사에 `User`의 생년월일이 필요하다.
- 배치: 보험료 자동이체, 만기 도래 안내, 실효/부활 처리.

## 핵심 흐름

청약 → 규칙 기반 자동 심사(언더라이팅) → 계약 → 매월 보험료 자동이체 → 만기 환급 / 미납 시 실효 / 부활.

- 계약 상태 머신(청약 → 유효 → 실효 → 부활 / 만기 / 해지)이 핵심이다.

## 새 모델 후보

`InsuranceProduct`, `Policy`, `PremiumPayment`, `Claim`.

## 완료 조건

보험료 미납 시 실효 배치가 돌고, 부활 시 미납분이 정산된다.
