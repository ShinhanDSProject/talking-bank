# Phase 6 — 증권

증권 계좌에 은행 계좌에서 예수금을 넣고, 가상 종목을 사고팔고, T+2 결제와 일일 평가가 배치로 돈다.

- 진입 조건: [Phase 3](03-product.md) 완료 (배치 인프라, 영업일 캘린더).
- 코어와의 연결점: 예수금 입금은 은행 계좌에서의 출금 — [송금 규칙](../04-domain.md#송금-규칙)을 따른다. `Account.accountType`에 `SECURITIES`, `Transaction.sourceType`에 `SECURITIES`가 추가된다.
- 배치: T+2 결제, 일일 포트폴리오 평가.

## 핵심 흐름

증권 계좌 개설 → 은행 계좌에서 예수금 이체 → 가상 종목 매수/매도 → 즉시 체결(가상) → T+2 결제 배치 → 일일 포트폴리오 평가.

- 종목 몇 개와 시세를 시드로 둔다. 실제 시세 연동은 향후 후보.
- 결제일 계산에 Phase 3의 영업일/공휴일 캘린더를 쓴다.

## 새 모델 후보

`SecuritiesAccount`, `Stock`, `Order`, `Execution`, `Holding`.

## 완료 조건

매수 체결 2영업일 뒤 결제 배치가 돌고, 평가액이 갱신된다.
