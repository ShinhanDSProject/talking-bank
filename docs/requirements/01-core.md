# 요구사항 정의서 — Phase 1 은행 코어

> "무엇을 만들지"를 화면 · 정책 · 기능 · 비기능 · 제외 다섯 표로 못 박는다. 화면 ID · 정책 수치 · REQ ID는 **이 문서가 주인**이고, PRD · UI 브리프 · Figma · 코드는 여기 있는 이름을 그대로 쓴다. 우선순위는 **필수 / 권장** 둘뿐이다. 필수가 전부 끝나야 Phase 1이 끝난다.

- 범위의 근거: [domains/01-core.md](../domains/01-core.md) · 공통 규칙: [04-domain.md](../04-domain.md) · API 계약과 인증 정책: [06-conventions.md](../06-conventions.md)
- 화면의 모양: 루트 `DESIGN.md` (PR #39). 여기서는 화면에 **무엇이 있어야 하는지**만 적는다.
