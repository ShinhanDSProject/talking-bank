# 요구사항 정의서 — Phase 2 대화형 뱅킹

> "무엇을 만들지"를 화면 · 정책 · 기능 · 비기능 · 제외 다섯 표로 못 박는다. 화면 ID · 정책 수치 · REQ ID는 **이 문서가 주인**이고, PRD · UI 브리프 · Figma · 코드는 여기 있는 이름을 그대로 쓴다. 우선순위는 **필수 / 권장** 둘뿐이다. 필수가 전부 끝나야 Phase 2가 끝난다.

- 범위의 근거: [domains/02-assistant.md](../domains/02-assistant.md) · Phase 1 요구사항: [01-core.md](01-core.md) · 공통 규칙: [04-domain.md](../04-domain.md) · API 계약과 AI 서비스 규칙: [06-conventions.md](../06-conventions.md)
- 화면의 모양: [DESIGN.md](../../DESIGN.md). 여기서는 화면에 **무엇이 있어야 하는지**만 적는다.
- 이 Phase의 원칙 하나: **AI는 돈을 움직이지 않는다.** 읽기와 초안 작성만 한다. 실행은 Phase 1의 이체 확인 화면과 이체 비밀번호(POL-023)가 그대로 맡는다.
